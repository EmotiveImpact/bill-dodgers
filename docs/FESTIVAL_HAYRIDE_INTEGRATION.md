# Hay Ride actual-main integration

`godot/tests/test_festival_hayride_integration.gd` runs the real `main.tscn`, production `main.gd`, shared festival combat, `world_three.gd`, Hay Ride extension and dedicated painter. **475 checks passed, zero failures** with Godot 4.6.3 headless on 2026-11-09. The process exited 0 and a separate strict log scan found no `SCRIPT ERROR`, `Parse Error`, `^ERROR:`, `ObjectDB instances leaked` or failing assertions. HOME, XDG data/config/cache and TMPDIR were isolated under `/tmp` for the run.

This is an integration-fixture report. It is **not** a full-route playthrough, framebuffer/screenshot comparison, physical handset test, mobile export or co-op certification. The full-route suite is separate. No production files, deployment, visibility, commits or push were changed by this test owner.

## Fixture boundaries

The suite deliberately relocates the player/camera and the one live deck, suppresses ordinary waves by setting their runtime thresholds to infinity, and supplies encounter clocks/HP/positions to isolate exact boundaries. Some interception tests add a runtime-only enemy, boss, crate or wall. Those additions do not imply such content is authored for 3-5. Many fixtures use invulnerability to avoid unrelated collisions; damage fixtures explicitly remove it. The probe subclass records calls to the real save, coin-drop and event functions and delegates to their original implementations. Audio is replaced with a request log, not audible-output evidence.

The source contract is `game/3-5/index.html`, especially shared carry/auto/end rules at 1170–1182, carrier/departure hooks at 1183–1237, late level ordering at 1295–1327 and `updateHarv` at 1328–1338, plus the imported immutable metadata. Component and renderer audits are in `FESTIVAL_HAYRIDE_PARITY.md` and `FESTIVAL_HAYRIDE_RENDERER.md`.

## Reproduction

From the repository root, provide writable isolated HOME/XDG/TMPDIR directories, then run:

```sh
/usr/local/bin/godot --headless --path godot \
  --script tests/test_festival_hayride_integration.gd
```

Reject the run if the process fails **or** its combined output contains `SCRIPT ERROR|Parse Error|^ERROR:|ObjectDB instances leaked|FAIL:`. A zero exit status alone is insufficient.
